Vì sao nền tảng Rust tạo khác biệt?

Số liệu đo thực tế qua /proc/<pid>/smaps_rollup trên Ubuntu Wayland/XWayland khi tải cơ sở dữ liệu lịch sử trò chuyện lớn.

~3.4 MBPSS khi chờ (~6.0 MB khi giải mã video)

Nhẹ hơn gấp 20 đến 40 lần helper C++/Qt5 gốc

Thay vì gánh thêm tiến trình GUI phụ nặng 80-150 MB RSS hoặc lớp dịch Wine tốn 300-500 MB RAM, zcall-engine xử lý toàn bộ âm thanh, video và chia sẻ màn hình chỉ với vài MB bộ nhớ vật lý.

< 1.2%tỷ trọng RAM của toàn bộ tầng Rust

Không rò rỉ bộ nhớ khi treo máy dài ngày

Trong tổng mức ~788 MB PSS khi mở nhiều cuộc trò chuyện lớn, nhân Chromium/Electron chiếm ~98.8% (~778 MB); toàn bộ hệ thống Rust của Zalux vận hành gọn gàng trong phần còn lại.

Thành phần hệ thống Bản gốc (C++/Qt5) hoặc chạy qua Wine Zalux trên Linux (Native Rust)
Daemon Call Engine chạy nền (Idle) ZaloCall C++ / Qt5 Widgets: ~80-150 MB RSS zcall-engine Rust thuần: ~3.4 MB PSS (~5.8 MB RSS)
Giải mã Video H.264 / HEVC trực tiếp Phụ thuộc tiến trình helper GUI phụ nặng nề --decode-pipe (0-frame delay): ~6.0 MB PSS (~12.0 MB RSS)
9 Module hệ thống N-API (.node) Nhiều dynamic library và framework rời ~15.4 MB trên đĩa sau khi strip, chạy trực tiếp trong tiến trình
Tổng RAM ứng dụng (nhiều DB chat lớn) ~650-950 MB (+300-500 MB nếu chạy qua Wine) ~788 MB PSS (Electron/UI Zalo ~778 MB, tầng Rust < 1.2%)

Đo kiểm trung thực: phần lớn RAM thuộc về nhân hiển thị web Electron của giao diện Zalo. Tầng Rust đảm bảo các tác vụ thời gian thực (VoIP/SFU, mã hoá SRTP, PipeWire ScreenCast, SQLite FTS5, JPEG XL) đạt tốc độ native trên Linux mà không làm nặng máy.

Một lệnh duy nhất. Không cần quyền root.

Cài nhanh tự động vào ~/.local/opt/zalux hoặc chọn đúng bản phân phối Linux của bạn để cài gói thư viện hệ thống kèm PipeWire và Portal.

Cài nhanh tự động (Khuyên dùng)

Tự tải bản phát hành mới nhất, tích hợp biểu tượng menu ứng dụng và tạo lệnh ~/.local/bin/zalux.

Terminal (Bash) 
curl -fsSL https://raw.githubusercontent.com/todo-laterx/zalux/main/scripts/bootstrap.sh | bash
Đã kiểm thử đầy đủ trên Wayland & X11
1. Gói thư viện hệ thống (Ubuntu 24.04+) 
sudo apt install libopus0 libpipewire-0.3-0t64 xdg-desktop-portal \
  pulseaudio-utils ffmpeg libgtk-3-0t64 libnss3 libx11-xcb1 \
  libxcb-dri3-0 libgbm1 libasound2t64 libsecret-1-0
2. Cài từ gói .deb hoặc kho mã 
git clone https://github.com/todo-laterx/zalux.git
cd zalux
./scripts/install-latest.sh
1. Gói thư viện hệ thống (Debian 12 / 13) 
sudo apt install libopus0 libpipewire-0.3-0 xdg-desktop-portal \
  pulseaudio-utils ffmpeg libgtk-3-0 libnss3 libx11-xcb1 \
  libxcb-dri3-0 libgbm1 libasound2 libsecret-1-0
2. Cài đặt Zalux 
git clone https://github.com/todo-laterx/zalux.git
cd zalux
./scripts/install-latest.sh
1. Gói thư viện hệ thống (Fedora / RHEL) 
sudo dnf install opus pipewire-libs xdg-desktop-portal \
  pulseaudio-utils ffmpeg gtk3 nss libX11-xcb libxcb \
  mesa-libgbm alsa-lib libsecret
2. Cài đặt hoặc đóng gói .rpm 
git clone https://github.com/todo-laterx/zalux.git
cd zalux
./scripts/install-latest.sh
1. Gói thư viện hệ thống (Arch Linux) 
sudo pacman -S opus libpipewire xdg-desktop-portal libpulse \
  ffmpeg gtk3 nss libx11 libxcb mesa alsa-lib libsecret git
2. Cài đặt hoặc dùng PKGBUILD 
git clone https://github.com/todo-laterx/zalux.git
cd zalux
./scripts/install-latest.sh
